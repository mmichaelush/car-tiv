# מערכת העיצוב

## הכלל היחיד

**אין ערך קשיח ברכיב.** כל צבע, מרווח, רדיוס, גודל וזמן מגיעים ממשתנה
ב-`src/styles/tokens.css`. רכיב שכותב `#a855f7` או `18px` שובר גם את ערכות
הנושא וגם את הגדרת הצפיפות.

## שלוש שכבות

```
tokens.css     סולמות גולמיים: פלטת סגול, ניטרלים, מרווחים, טיפוגרפיה, רדיוסים
themes.css     מה שצבע *אומר*: --surface, --text, --brand, --line
components/    שימוש בלבד — אף פעם לא הגדרה
```

רכיב משתמש רק בשכבה האמצעית. `--purple-500` לא מופיע בשום קובץ רכיב.

## ערכות נושא

| ערכה       | אופי                                                     |
| ---------- | -------------------------------------------------------- |
| `purple`   | ברירת המחדל — הסגול הכהה שהאתר תמיד היה                  |
| `midnight` | כחול עמוק עם זהב                                         |
| `ocean`    | טורקיז כהה                                               |
| `black`    | שחור מלא — על מסך OLED פיקסל כבוי לא צורך חשמל           |
| `light`    | בהיר                                                     |
| `sepia`    | חם ודל בכחול — לקריאה ארוכה, ובעיקר בלילה                |
| `contrast` | ניגודיות גבוהה — לא "כהה יפה יותר", אלא קריאוּת מקסימלית |
| `system`   | לפי מערכת ההפעלה                                         |

מעליהן `data-accent` (סגול, כחול, ירוק, כתום, זהב) שמשנה רק את צבע ההדגשה.

הכול עובד דרך חמש תכונות על `<html>`: `data-theme`, `data-accent`,
`data-density`, `data-text-size` ו-`data-motion`.
`public/theme-bootstrap.js` כותב אותן **לפני** הציור הראשון — זו הסיבה שאין
הבזק של הצבע הלא נכון. הוא מכפיל בכוונה כמה שורות מ-`preferences.ts`: לייבא
את המודול שם היה גורר את כל ה-bundle למסלול הקריטי בשביל חמש תכונות. יש בדיקה
(`tests/ui/preferences.test.ts`) שמוודאת ששני הצדדים מסכימים על רשימת התכונות.

### בחירת ערכה

הבחירה נעשית **בהסתכלות ולא בקריאה**: כל ערכה מוצגת כריבוע שצבוע בצבעי הרקע
וההדגשה שלה עצמה. "אוקיינוס" לא אומר כלום; שני ריבועים אומרים הכול. הצבעים
ב-`THEME_OPTIONS` הם ליטרלים ולא נקראים מה-CSS — תצוגה מקדימה חייבת להיראות
לפני שהערכה מוחלת, ולכן אי אפשר לשאול את המסמך על הטוקנים של עצמו.

## גודל טקסט

`data-text-size` (`small` · `medium` · `large` · `xlarge`) מכפיל את
`--text-scale`, וכל סולם הטיפוגרפיה נגזר ממנו. **בכוונה נפרד מצפיפות**: מי
שצריך אותיות גדולות יותר לא בהכרח רוצה כרטיסים גדולים יותר, ואלה שתי בקשות
שונות.

## תנועה

שתי דרכים לבקש פחות: הגדרת מערכת ההפעלה (`prefers-reduced-motion`) והתיבה
שלנו (`data-motion="reduced"`). **מערכת ההפעלה תמיד מנצחת** — שום תיבה אצלנו
לא מחזירה אנימציות למי שהמכשיר שלו ביקש להפסיק אותן.

מעבר בין עמודים משתמש ב-View Transitions: ארבע שורות CSS, והדפדפנים שלא
תומכים מתנהגים בדיוק כמו קודם.

## טבעת פוקוס

`--focus-ring` הוא טוקן נפרד ולא "צבע המותג". ברוב הערכות הם זהים, אבל צבע
ההדגשה ניתן להחלפה על ידי המשתמש בכל רגע — טוקן נפרד מבטיח שהטבעת לא תיעלם
לתוך הרקע בגלל בחירת צבע.

## צפיפות

`compact` · `comfortable` · `large` משנות חמישה משתנים בלבד: רוחב מינימלי
לכרטיס, מרווח ברשת, ריפוד, גובה פקד ורדיוס. שאר המערכת נגררת אחריהם.

## רשת

```css
grid-template-columns: repeat(auto-fill, minmax(var(--grid-min), 1fr));
```

מספר העמודות נובע מרוחב המסך ומהצפיפות שהמבקר בחר — לא מסולם media queries.
מסך רחב + צפיפות קומפקטית = יותר עמודות, בלי קוד נוסף.

## רכיבים

| מחלקה                                                          | תפקיד                                                       |
| -------------------------------------------------------------- | ----------------------------------------------------------- |
| `.btn` + `--primary/--secondary/--ghost/--danger/--sm/--block` | כל הכפתורים                                                 |
| `.icon-btn`                                                    | כפתור אייקון עגול — תמיד עם `aria-label`                    |
| `.chip`                                                        | קטגוריה, תגית, בחירה. `aria-pressed` הוא מצב הבחירה         |
| `.input` `.select` `.textarea` `.field` `.check`               | טפסים                                                       |
| `.video-card` `.video-row` `.channel-card`                     | תוכן                                                        |
| `.skeleton`                                                    | טעינה — **רק בזמן בקשה אמיתית**, אף פעם לא על טיימר         |
| `.empty-state` `.form-status`                                  | מצבים ריקים והודעות                                         |
| `.dialog`                                                      | על `<dialog>` המקורי: מלכודת פוקוס, Escape ו-backdrop בחינם |
| `.toast`                                                       | אישור פעולה. אזור אחד, `aria-live="polite"`                 |
| `.pagination`                                                  | ניווט בין עמודים                                            |

## RTL

הכול בתכונות לוגיות: `inset-inline-start`, `margin-inline`, `padding-block`.
אין `left`/`right` בשום מקום. תוכן לטיני בתוך משפט עברי מקבל `.ltr`.

## נגישות

- טבעת פוקוס נראית ב-`:focus-visible`, בשני צבעים מנוגדים לרקע.
- דילוג לתוכן בכל עמוד.
- כל אייקון-כפתור עם `aria-label`; כל אייקון דקורטיבי עם `aria-hidden`.
- `prefers-reduced-motion` מכבה כל אנימציה.
- כרטיס = קישור אמיתי אחד (כותרת), עם שטח לחיצה מורחב ב-`::after`.
  לא `<div onclick>` — כדי שגלגל אמצעי, "פתח בלשונית חדשה" וקורא מסך יעבדו.

## אייקונים

SVG מוטבע, סט אחד, ~250 בתים לאייקון, יורש `currentColor`.
האתר הישן טען ~215KB של Font Awesome עבור עשרים אייקונים, במסלול הקריטי.
