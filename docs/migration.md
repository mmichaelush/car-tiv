# ייבוא הקטלוג הישן

## התוצאה

מתוך `data/videos/*.json`:

| מדד                       | ערך                   |
| ------------------------- | --------------------- |
| שורות במקור               | 7,876                 |
| יובאו                     | **7,876**             |
| נדחו                      | 0                     |
| כפילויות                  | 0                     |
| שגיאות                    | 0                     |
| אזהרות                    | 166                   |
| ערוצים                    | 416 (כולל 79 מומלצים) |
| תגיות                     | 10,732                |
| סרטונים עם יצרן/דגם מזוהה | 5,550                 |

166 האזהרות הן 165 סרטונים ללא תיאור ותאריך אחד לא תקין (`01/01/2`).
כולם יובאו — אזהרה לא מפילה שורה, כי לאבד סרטון גרוע מלייבא סרטון בלי תיאור.

## איך

```bash
npm run catalog:build          # → build/catalog/*.sql + report.md + report.json
npm run catalog:import:local   # מחיל אותם, קובץ אחרי קובץ
```

הבנייה לא נוגעת בבסיס נתונים. היא מייצרת קבצים ודוח, וההחלה היא צעד נפרד
ומכוון. `import-catalog.ts` עוצר בקובץ הראשון שנכשל, ולא ממשיך הלאה.

## מה עברה כל שורה

1. **מזהה** — חייב 11 תווים תקינים. אחרת השורה נדחית ומדווחת.
2. **כפילות** — סרטון שמופיע בשני קבצי קטגוריה מיובא פעם אחת; הראשון מנצח.
3. **תאריך** — `17/09/2024` הוא 17 בספטמבר. `new Date()` היה קורא את זה כ-9 בספטמבר
   בחלק מהסביבות. `parseCatalogDate` גם דוחה תאריכים שלא קיימים (31/02).
4. **משך** — `"8:42"`, `"1:02:15"`, `"PT8M42S"` ו-`"59"` (Shorts) → שניות.
5. **ערוץ** — שם עם רווחים מיותרים מנורמל, ו-409 שמות חוזרים הפכו ל-409 רשומות.
   ל-15 ערוצים היו כמה כתובות avatar; נבחרה הראשונה.
6. **תגיות** — מנורמלות ל-slug. **תגית שרק חוזרת על שם הערוץ או הקטגוריה נזרקת**:
   היו 13,508 מופעים כאלה, והם היו מזהמים את רשימת התגיות הפופולריות.
7. **רכב** — יצרן ודגם מזוהים מהכותרת, מהתגיות ומהתיאור מול
   `data/reference/vehicles.json` (51 יצרנים, 313 דגמים). דגם מתקבל רק אם
   היצרן שלו הוזכר — כך ש-"Ford Focus" נתפס ו-"focus" לבדו לא.

## מה עוד לא נמחק

`data/videos/*.json` נשארים. הם המקור לייבוא, ה-fixtures לבדיקות והבסיס
לתמונת המצב הסטטית. אין למחוק אותם עד שהייבוא אומת ב-production.
